# Chrome Web Store submission

Everything the listing form asks for, ready to paste. Build the upload with
`npm run package` (produces `dist-zip/echomirror-chrome-<version>.zip`).

Publishing needs a Chrome Web Store developer account for the EchoMirror
organisation, which this contribution does not have — the package and copy
below are submission-ready for a maintainer with publisher access.

## Store listing

**Name** — EchoMirror — Mood Check-in

**Summary** (132 char limit)

> Log how you are feeling in two clicks and get a gentle daily reminder if you have not checked in yet.

**Category** — Workflow & Planning

**Language** — English (United States)

**Description**

> EchoMirror turns a daily mood check-in into a two-click habit.
>
> Click the toolbar icon, pick a score from 1 to 10, optionally add a note and
> a few tags, and your entry is saved to your EchoMirror account. Your current
> streak is right there in the popup.
>
> If you have not checked in by the time you choose, EchoMirror shows a single
> quiet reminder — never more than one a day, and never on a day you have
> already logged. Reminders can be switched off entirely in the settings.
>
> FEATURES
> - Two-click mood check-in: score, optional note, optional tags
> - Your streak, visible every time you open the popup
> - One configurable daily reminder, with a full opt-out
> - Works with your existing EchoMirror account and history
>
> REQUIREMENTS
> An EchoMirror API key, free at echomirror.dev/developers. Paste it into the
> extension settings once.
>
> PRIVACY
> The extension talks to api.echomirror.dev and nowhere else. It does not read
> the pages you visit, has no content scripts, and collects no analytics. Your
> API key and preferences stay in your browser profile.
>
> EchoMirror is open source: github.com/Echo-Mirror-Butler/echomirror-sdk

## Privacy practices tab

**Single purpose**

> The extension has one purpose: recording a daily mood check-in to the user's
> EchoMirror account and reminding them to do so.

**Permission justifications**

| Permission | Justification |
| --- | --- |
| `storage` | Stores the user's API key, their reminder preferences and the local marker for whether they have already checked in today. The background service worker is suspended between events, so this state cannot be held in memory. |
| `alarms` | Schedules the single daily reminder. `setTimeout` does not survive service worker suspension, so `chrome.alarms` is the only way to run code at the user's chosen time. |
| `notifications` | Displays that reminder — at most one notification per day, and none if the user has already logged a mood or turned reminders off. |
| Host: `https://api.echomirror.dev/*` | The EchoMirror API, where mood entries are created and the streak is read. No other host is contacted. |

**Remote code** — No. All JavaScript is bundled into the package; the CSP is
`script-src 'self'; object-src 'self'; base-uri 'self'`.

**Data usage disclosures**

- Collected: *Personal communications* (the optional free-text note) and
  *Health information* (the mood score and tags), transmitted only to the
  user's own EchoMirror account.
- Not collected: location, financial data, authentication data beyond the
  user-supplied API key, personally identifiable information, web history,
  website content, user activity.
- Not sold to third parties, not used or transferred for purposes unrelated to
  the item's single purpose, not used to determine creditworthiness.

**Privacy policy URL** — https://echomirror.dev/privacy

## Assets checklist

| Asset | Requirement | Status |
| --- | --- | --- |
| Store icon | 128x128 PNG | `dist/icons/icon128.png`, generated by the build |
| Screenshots | 1–5, 1280x800 or 640x400 PNG | capture from the running extension, see below |
| Small promo tile | 440x280 PNG (optional) | not required for submission |

Screenshots must show the real UI, so they are captured rather than checked in:

1. `npm run build`, load `dist/` unpacked, configure a key.
2. Capture the popup mid-check-in (score, note, tags selected).
3. Capture the options page.
4. Capture the reminder notification.
5. Scale each to 1280x800 on a plain background.

## Submission checklist

1. Bump `version` in `package.json` and `scripts/manifest.mjs` (a unit test
   keeps them in step).
2. `npm test && npm run package`.
3. Chrome Web Store Developer Dashboard → **New item** → upload the zip.
4. Paste the listing copy and privacy answers above, attach the screenshots.
5. Submit for review. Expect a few days; a permission-justification mismatch is
   the usual cause of rejection, so keep this file in sync with the manifest.
