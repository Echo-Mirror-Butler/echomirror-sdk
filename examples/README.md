# EchoMirror Examples

Runnable examples for the EchoMirror SDK packages:

- [React app](react-app/README.md): React, mood, social, Stellar, and WASM SDK packages.
- [Soroban demo](soroban-demo/README.md): Stellar wallet connection with the current Stellar SDK.
- [Vanilla JavaScript](vanilla-js/README.md): direct SDK client configuration and mood logging.
- [SwiftUI app](swiftui/EchoMirrorExample/README.md): native iOS/macOS example using the Swift package.

Each JavaScript example can be built from its own directory with:

```bash
npm install
npm run build
```
