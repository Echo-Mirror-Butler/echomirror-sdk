# EchoMirror SwiftUI Example

This SwiftUI app demonstrates mood logging and Stellar balance lookup through
`EchoMirrorSDK`. The SDK package links a local XCFramework, so prepare it from
the repository root on a Mac with Xcode and the Rust targets required by the
package build script:

```bash
packages/swift/EchoMirrorSDK/Scripts/build-xcframework.sh
swift test --package-path packages/swift/EchoMirrorSDK
```

Then create an iOS App project in Xcode (iOS 15 or later), choose **File > Add
Package Dependencies > Add Local...**, and select
`packages/swift/EchoMirrorSDK`. Add `ContentView.swift` and
`EchoMirrorExampleApp.swift` from this directory to the app target. Remove the
app entry-point file generated by Xcode so the example's `@main` declaration is
the only one. Set the API key and user ID in `ContentView` before running on a
simulator or device.

This directory contains the SwiftUI source files rather than an `.xcodeproj`,
so it is not opened or built as a standalone Xcode project. The local package
also cannot be added until its XCFramework has been generated.
